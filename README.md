# Bloom.me — VitaTree

เกมปลูกต้นไม้แห่งชีวิตที่เติบโตจากพฤติกรรมจริงของผู้ใช้ ใน 3 ด้าน: ความรู้ · จิตใจ · สุขภาพ

React 19 + Vite + TypeScript · พร้อมเชื่อม API แล้ว

---

## เริ่มใช้งาน

```bash
npm install
cp .env.example .env
npm run dev
```

ค่าเริ่มต้นคือ `VITE_API_MODE=mock` — รันได้ทันทีโดยไม่ต้องมี backend
ข้อมูลจำลองถูกบันทึกลง localStorage จึงไม่หายเมื่อรีเฟรช

```bash
npm run typecheck   # ตรวจชนิดข้อมูลทั้งโปรเจกต์
npm run build       # สร้างไฟล์สำหรับ production
npm run preview     # ทดสอบไฟล์ที่ build แล้ว
```

## โครงสร้างที่ควรรู้

```
src/
  components/
    ui/            ← ชั้น primitive: Surface, Button, Overlay, SceneFrame
    common/        ← ErrorBoundary, RouteFallback
    tree/          ← ต้นไม้แห่งชีวิต (คอมโพเนนต์ที่แพงที่สุดในแอป)
    quest/
      games/       ← ไฟล์เกมของแต่ละเควส แยกกันคนละไฟล์
        learning/  ← 10 เควสหมวดการเรียนรู้
        physical/  ← 5 เควสหมวดสุขภาพกาย
      mental/      ← หน้าเควสสุขภาพจิต + แดชบอร์ด + คัดกรอง + กล่องพยาบาล
  context/         ← User / Progress / UI / Mental (+ AppContext เป็นสะพานรวม)
  services/        ← ชั้นเชื่อม API — เปลี่ยน mock ↔ live ที่ .env ไฟล์เดียว
    api/           ← 1 โดเมน 1 ไฟล์
    mock/          ← ข้อมูลจำลอง
  hooks/           ← useCountdown, usePersistentState, useMediaQuery ฯลฯ
  config/          ← โทเคน catalog เควส ท่าเคลื่อนไหว ระบบคัดกรอง
docs/
  DB_CHANGES.md    ← ตัวแปร/ตารางที่ต้องเพิ่มในฐานข้อมูล  ← อ่านก่อนต่อ backend
  MIGRATION.md     ← สรุปสิ่งที่เปลี่ยน + สิ่งที่ยังต้องทำต่อ
```

## หลักการที่โปรเจกต์นี้ยึด

**สไตล์** — เขียน CSS ในไฟล์ `.css` วางคู่คอมโพเนนต์ ใช้โทเคนจาก `index.css`
ห้ามเขียนสีดิบและห้ามฝัง `<style>` ในคอมโพเนนต์ มีโทเคน 2 ตระกูล:
ตระกูลปกติสำหรับ UI สว่าง และตระกูล `--ae-*` (Aether) สำหรับฉากเวทมนตร์

**อาร์ตเวิร์ก** — emoji ใช้เป็นตัวสำรองเท่านั้น ไม่ใช่อาร์ตจริง
วางไฟล์ที่ `public/assets/images/decorations/<itemId>.webp` แล้วระบบจะใช้ภาพนั้นเอง

**ข้อมูล** — ข้อมูลของเซิร์ฟเวอร์อยู่ใน TanStack Query เท่านั้น
ข้อมูลฝั่งเครื่องผู้ใช้ (ตั้งค่า ตำแหน่งไอเทม) อยู่ใน localStorage
ห้ามเก็บข้อมูลเซิร์ฟเวอร์ลง localStorage เพราะจะกลายเป็นแหล่งความจริงคู่ขนาน

**การเคลื่อนไหว** — ใช้ชุดท่าจาก `config/motion.ts` และเคารพ `prefers-reduced-motion` เสมอ
อนิเมชันที่วนไม่จบและไม่ได้เกิดจากการกระทำของผู้ใช้ ถือเป็นสิ่งรบกวน ไม่ใช่สิ่งดึงดูด

**สุขภาพจิต** — แบบคัดกรองเป็นเครื่องมือดูแลเบื้องต้น ไม่ใช่การวินิจฉัย
ทุกหน้าต้องมีทางออกให้ผู้ใช้เสมอ และสายด่วน 1323 ต้องกดถึงได้เมื่อความเสี่ยงสูง
